# agent-board

Локальная доска задач для облачных агентов. Запускается на Маке (`node server.mjs`, порт 5194, только 127.0.0.1). Задачи лежат в `data/tasks.json` (в git не попадает). В облако уходит текст задачи в промпте `claude --cloud`; ход работы и результат доска читает с GitHub через `gh`, поэтому токены в браузере не нужны.

## Как устроено

- `server.mjs` состояние задач, синхронизация с GitHub раз в 20 с, API для интерфейса.
- `dispatch.py` запуск `claude --cloud` через pty: без интерактивного терминала CLI отказывается создавать облачную сессию.
- `app.js`, `index.html`, `style.css` интерфейс без сборки.
- `config.json` проекты: репозиторий, локальная папка, шаблоны ссылок на превью.

## Модель состояний

`backlog` → `running` → `review` → `done` (или `failed`, `closed`). Статус выводится из draft-PR ветки `claude/task-N`: draft и «Ход работы» значит идёт работа; «## Отчёт» без draft значит готово к проверке; «СБОЙ:» значит ошибка; влитый PR значит принято. Доработка уходит в ту же облачную сессию через `claude -p … --cloud <session_id>`.

## Модель и усилие задачи

`config.json` держит `models` (алиасы claude: sonnet, opus, fable, haiku) с `defaultModel` и `efforts` (low, medium, high, xhigh, max) с `defaultEffort`. Выбор хранится в задаче и передаётся как `claude --model <алиас> --effort <уровень> --cloud …`. Допустимые уровни сверены с самим CLI. Действуют ли `--model` и `--effort` на облачные сессии, в документации не сказано: проверять по шапке сессии на claude.ai и по строке «Модель:» в отчёте агента. Доработка идёт в ту же сессию и модель не меняет.

## Правила

- Из GitHub и от пользователя в DOM только через `textContent` или `md()`, которая экранирует ввод.
- Изменяющие запросы принимаются только с `Content-Type: application/json` и с Host `localhost`/`127.0.0.1`: защита от запросов с чужих сайтов.
- Папка проекта должна быть доверенной для Claude (один раз запустить в ней `claude` и ответить «Yes, I trust»), иначе `dispatch.py` вернёт `trust`.
- Перед отправкой сервер переключает папку проекта на `staging`: облако клонирует текущую ветку.

## Открыто

- Полный лог облачной сессии программно не отдаётся (нет API): доска показывает ход из PR, коммиты, проверки и ссылку на сессию на claude.ai.
- Зависшая сессия остаётся в «В работе»: после 30 минут без PR панель подсказывает открыть сессию.
