# Доска агентов

Панель: https://ilyavasiliev1.github.io/agent-board/ · Демо-проект: https://github.com/ilyaVasiliev1/coffee-site

Один проект, два исполнителя над одними и теми же задачами:

| | Исполнитель А | Исполнитель Б |
|---|---|---|
| Кто | Claude в облаке Anthropic | Hermes Agent с моделью Claude |
| Запуск | с Мака: `harness/tools/board.sh coffee-site send N claude` (панель копирует команду) | кнопкой в панели, стартует GitHub Actions |
| Оплата | кредиты облачных сессий ($250, до 5 ноября) | `ANTHROPIC_API_KEY` Console |
| Ноутбук после запуска | можно закрыть, когда напечатана ссылка на сессию | можно закрыть сразу |
| Доработка | `board.sh coffee-site rework N "…"` в ту же сессию | кнопка «На доработку» |

## Разовая настройка

1. Токен для панели: GitHub → Settings → Developer settings → Fine-grained tokens → репозиторий `coffee-site`, права Issues, Pull requests, Contents: Read and write. Вставить в панели по кнопке «Доступ».
2. Для Hermes: в `coffee-site` → Settings → Secrets → Actions → `ANTHROPIC_API_KEY`.
3. Для Claude: `claude auth login` на Маке и доступ облака к GitHub (`/web-setup` или Claude GitHub App на репозитории).

## Сценарий проверки

Одинаковая задача для обоих исполнителей, чтобы сравнить: «Добавь в меню позицию Раф за 290 ₽ в категорию Эспрессо и тест на неё».

1. Панель → «Новая задача», исполнитель Claude, создать. Скопируется команда.
2. Терминал на Маке: вставить команду. Дождаться строки «Сессия … Можно закрывать ноутбук» и закрыть крышку.
3. Через 10–15 минут открыть панель с телефона или Мака: карточка должна быть в «На проверке» с отчётом, ссылкой на превью и на отчёт тестов.
4. Открыть превью: позиция есть. Открыть отчёт тестов: есть скриншоты.
5. «На доработку»: «Сделай цену 300». Выполнить скопированную команду. Карточка вернётся в «На проверке».
6. «Принять»: PR вливается в `staging`, через минуту позиция видна на https://ilyavasiliev1.github.io/coffee-site/staging/.
7. То же самое с исполнителем Hermes (шаги 1, 3–6; запуск кнопкой «Отправить на исполнение»).

## Что сравнивать

Дошла ли задача до «На проверке» без вмешательства; качество и честность отчёта; сработали ли тесты; сколько минут; сколько денег (счётчик кредитов на claude.ai/settings/usage и расход в Console); понятность правок при доработке.

## Что ещё не проверено

- Закрытие ноутбука сразу после ссылки на сессию: по документации сессия живёт без Мака, на практике не пробовано.
- Хватает ли облачной сессии прав, чтобы `gh` ставил метки и писал комментарии в issue.
- Установка Hermes в Actions (`install.sh`) и имена его параметров: сверено по документации, не запускалось.
- Зависшая сессия остаётся в «В работе»: сторожа по таймауту нет.
