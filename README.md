# Доска агентов (локальная)

Запуск: `cd ~/Developer/laboratory/agent-board && node server.mjs`, затем http://localhost:5194

Задачи ставятся на Маке и уходят в облачную сессию Claude. Ноутбук после отправки можно закрыть: сессия продолжается в облаке и оставляет результат в GitHub (draft-PR с ходом работы, затем отчёт и превью). Когда откроете Мак и запустите доску, она сама подтянет состояние.

## Разовая настройка

1. `gh auth login` (уже сделано) и `claude auth login`.
2. Подтвердить доверие к папке проекта: `cd ~/Developer/laboratory/coffee-site && claude`, ответить «Yes, I trust this folder», выйти (`/exit`).
3. Облако должно иметь доступ к GitHub (`/web-setup` в Claude Code или Claude GitHub App на репозитории).

## Сценарий проверки

1. «Новая задача»: «Добавь в меню Раф за 290 ₽ в категорию Эспрессо и тест». Галочка «Сразу отправить» включена.
2. Дождаться в ленте события «Облачная сессия запущена» со ссылкой. После этого можно закрыть ноутбук.
3. Открыть карточку (после открытия Мака): ход работы из PR, коммиты, проверки, ссылка на живой лог сессии на claude.ai.
4. Статус «На проверке»: открыть превью и отчёт тестов со скриншотами.
5. «На доработку» с текстом «сделай цену 300»: правка уходит в ту же сессию.
6. «Принять»: PR вливается в `staging`, через минуту изменение на https://ilyavasiliev1.github.io/coffee-site/staging/.

## Что смотреть в логах

Полный лог сессии (каждая команда и рассуждение) доступен только на claude.ai по ссылке из карточки: программного доступа к нему нет. В самой доске видно: ход работы, который агент ведёт в теле PR, коммиты, результаты проверок и события доски.

## Что не проверено

- Реальный запуск облачной сессии из панели: упирался в подтверждение доверия к папке.
- Хватает ли облачной сессии прав у `gh` (draft-PR, правка тела PR).
- Закрытие ноутбука сразу после ссылки на сессию.
